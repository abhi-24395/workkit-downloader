# WorkKit Downloader

A download manager for Mac. It splits big files across parallel connections, pauses and resumes safely,
and saves video streams as MP4s that play in QuickTime, on iPhone and on Windows. A Chrome extension sends
links and playing videos straight to the app.

Product page, pricing and install guide: **https://www.workkit.in/downloader/**

This repository hosts the release downloads. The app is not open source.

## Download (1.0)

Get the files from the [latest release](https://github.com/abhi-24395/workkit-downloader/releases/latest).

| What | File |
|---|---|
| macOS 12 Monterey or later, Apple silicon (M1 or newer) | `WorkKitDownloader-1.0.dmg` |
| Chrome extension (optional; Load unpacked) | `WorkKitDownloader-Chrome-extension-1.0.zip` |

Windows is coming.

The app is signed with WorkKit's own certificate, not Apple's paid one, so macOS says it could not verify
it the first time you open it. The [install guide](https://www.workkit.in/downloader/#install) shows the
one-time **Open Anyway** step. Each release lists SHA-256 checksums of its files.

## What it won't download

YouTube and Instagram (their terms don't allow it), DRM-protected video, and live streams.

## Privacy

No account, no analytics, no telemetry. Downloads go straight from the website to your Mac, the license
key is checked offline, and the extension never copies your cookies or passwords.
Full list: https://www.workkit.in/downloader/#privacy
